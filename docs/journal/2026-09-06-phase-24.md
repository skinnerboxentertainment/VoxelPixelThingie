**One thing the full suite taught.** Run alone, the keyboard test takes
five seconds. Run with the whole chromium suite in parallel on this
machine, its many awaited steps on a WebGL page overran the default
30 s budget once; it now declares 120 s, as the GPU spec does. The
photon spec's latency gate also tripped once under the same load
(5.5 s for a packet that takes 1 ms alone), which is the machine, not
the change; CI runs one worker.

**Not done.** A WebGL canvas itself cannot be made accessible; its
controls and its text twin are what the audit covers, and the scope note
in PLAN-4.md says so. The Pixi demo was not touched. No screen reader was
driven by hand; axe and the keyboard path are the automated half.
