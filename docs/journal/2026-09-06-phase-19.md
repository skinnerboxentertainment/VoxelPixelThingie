**The defect the oracle found.** The first run of "a refused emit changes
nothing" failed: the emission had changed. `setPassport` reported its
event before applying, as its comment said, but `emit`, `setPresent`,
and `move` applied first and reported after, in both `VoxelPixelBit` and
`FlatGrid`. Every mutator now reports then applies, so a sink that
refuses an event leaves the bit as it was. One visible consequence: the
reference `Grid` now records `presence` before the `unlinked` events it
causes rather than after, which is the honest order (a refused presence
must unlink nothing); two assertions that expected `presence` last were
changed to expect it first. `FlatGrid`, which derives links, emits no
`unlinked` events and is unaffected.

**What was built.** `src/policy.ts` (vocabulary, validation, matching,
`judge`, the refusal record, the reserved-key guard); `SceneSink` keeps a
policy per bit, judges at record time, enqueues the refusal at the
refused event's seq, and throws `PolicyError`; `InProcessPool` turns a
refused request into a failed audit; the durable activity marks a
refusal non-retryable; MCP `get_policy` and error surfacing on `emit`,
`remove_bit`, `request_job`; `scripts/export-policy.ts` (ODRL 2.2);
tees in the MCP server, its test, and the Three.js demo now put the
ledger's sink first so a recorder never holds a refused event;
`tests/policy.test.ts` and a policy case in `tests/mcp-scene.test.ts`.

**Decisions (ADR 0014).** The container stays policy-blind: the door is
the sink, which every persisted change passes through. Replay, the
policy's own records, and link bookkeeping are exempt. ODRL is the
export, not the contract.

**Not done.** The reference scene's origin bit was not given a policy:
that would change its ledger and so its digest, which journals, the
pinned pack, and the memory all cite; the policy is demonstrated on the
built-in scene instead. An in-memory grid without a scene sink is open;
the demos before a save are such grids. Capability tokens for delegation
between parties are deferred until there is a second party.
