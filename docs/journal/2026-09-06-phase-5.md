`gh release view v0.1.0` exists with a changelog of six features, two

**Three things that went wrong and what was done.**

- PR #30 merged while the rehearsal's carve step was still failing
  locally, because the command chain did not gate the merge on the
  rehearsal result. The failure was a stale baseline read during orbit
  damping, not a model defect; a probe showed the carve exposing nodes
  240 to 244 within 100 ms. Fixed in #34 with a settle wait. The lesson is
  recorded here: a chain that ends in `gh pr merge --auto` must start
  with the oracle and stop on its failure.
- TypeScript 7 had arrived through Dependabot and typedoc 0.28 supports
  up to 6.0. Pinned to 6.0.x with a Dependabot ignore on that major.
- The release-please PR could never merge on its own: commits pushed
  with the Actions token do not trigger workflows, so the required
  checks never ran. Closing and reopening the PR as a user triggered
  them. Every future release PR needs that step, or a personal token for
  the release workflow.

**Not done.** WebXR on hardware. A GitHub Project board. Retention policy
