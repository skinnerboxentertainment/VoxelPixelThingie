# 2026-09-06, Phase 7: Flat-array store

**Merged.** Container contract and conformance suite (#60). FlatGrid (#62).
Benches, SPEC v0.5, ADR 0007, default-container switch (this entry's PR).

**Oracles, all Verified this session.**

- #57: eleven conformance tests pass against Grid with every Phase 1 to 6
  number reproduced.
- #58: the same eleven pass against FlatGrid; the reference scene's digest
  is identical from both containers under a perspective and an
  orthographic camera; FlatGrid emits no link events and the same counts
  of every other type.
- #59, from `npm run bench:containers`, one run each, forced GC:

| Container | Size | Heap | B/bit | cameraMoved | renderList | evaluate |
|-----------|------|-----:|------:|------------:|-----------:|---------:|
| FlatGrid | 64³ | 64 MB | 254 | 3.41 ms | 1.36 ms | 10.81 ms |

The ticket asked for under 400 B/bit, under 16 ms cameraMoved, and under
8 ms renderList at 64³. All three hold with room.

In the Three.js demo, `npm run bench:frame 32` on the flat container:
orbit p50 16.7 ms, p95 16.9 ms, vsync-locked as before, and the model
pass fell from 3.0 ms to 1.6 ms.

**Decision.** FlatGrid is the default container; Grid is the reference.
ADR 0007 has the reasoning and the full table.

  cross-container digest did.

  commitlint and the chain it was in polled for a PR that never existed.
  The chain now stops on the commit result.
