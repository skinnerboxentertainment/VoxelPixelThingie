**What was built.** The server on the official TypeScript SDK (pinned
1.30.0, `zod` beside it). Tools: `list_bits`, `get_bit`, `get_history`,
`emit`, `set_passport`, `remove_bit`, `request_job`, `get_audit`, each
with a schema; every mutation goes through `grid.wrangle` with the
connected client's name as actor. Resources: the manifest, `spec://`
sections split from SPEC.md by heading, `adr://` records from
`docs/adr/`, and `oracles://all`, the named tests of every suite, so an
attached agent orients in one read. `npm run mcp` serves the built-in
reference scene or a folder opened for writing; `.mcp.json` at the root
points Claude Code at it.

**Decisions.** No side doors: a tool either reads or mutates through the
model's own API, so the conformance guarantees hold for an agent as for a
person. The SDK is pinned; Dependabot proposes moves.

**Not verified here.** Claude Code itself was not attached from this
session, which cannot load a new MCP server mid-run; the stdio probe above
is the same protocol over the same transport with a different client
name. The first Claude Code attach is Oscar's to run: open the repository
in a new session, and `.mcp.json` does the rest.
